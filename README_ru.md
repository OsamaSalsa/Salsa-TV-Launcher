## 🚀 Универсальное решение

Большинство современных ТВ-лаунчеров перегружены навязчивой рекламой, тяжелыми видеопревью и медлительным интерфейсом.

**Salsa TV Launcher** создан как полная противоположность: чистый, молниеносный, легковесный медиахаб без рекламы, слежки и фонового мусора.

### ✨ 7 встроенных ключевых модулей
1. **🚀 Сверхбыстрый и легкий лаунчер**: Мгновенный запуск, параллельная фоновая загрузка значков на всех ядрах процессора и плавная навигация 60 FPS.
2. **📺 Встроенный IPTV-плеер с избранным на главном экране**: Поддержка плейлистов M3U и воспроизведение любимых каналов в 1 клик.
3. **🎥 MiniTube**: Оптимизированный интерфейс YouTube Leanback для ТВ с быстрым воспроизведением в гостевом режиме.
4. **📥 Mini Downloader**: Высокоскоростной загрузчик файлов и APK с умным автоустановщиком в один клик.
5. **🛒 Salsa Store**: Удобный веб-каталог для поиска и установки приложений для Android TV.
6. **🕹️ 4 игровых портала**: Тысячи мгновенных онлайн-игр HTML5 без необходимости скачивания (**CrazyGames**, **Poki**, **Playhop**, **EasyGames**).
7. **🛡️ Блокировщик рекламы на уровне системы**: Встроенный AdGuard DNS защищает весь телевизор от рекламы, баннеров и трекеров.

* **Корректная работа внешней заставки (`Отключено`)**: При отключении встроенной заставки приложение снимает блокировку сна экрана (`FLAG_KEEP_SCREEN_ON`), позволяя системной или сторонней заставке запускаться вовремя.

  * **Слайд-шоу фотографий (`Slideshow`)**: Отображение фото из папки на устройстве/USB, выбранных снимков или 4K-галерей с настройкой времени показа (`5 сек`–`5 мин`), движением **Ken Burns / Плавный зум / Статично**, 6 переходами, атмосферными эффектами (**Падающий снег ❄️**, **Светлячки ✨**, **Дождь 🌧️**, **Осенние листья 🍂**, **Сакура 🌸**, **Звезды ⭐**, **Боке 🔮**), часами в углу и чистыми музыкальными треками (**Bossa Nova**, **Smooth Jazz**, **Calm Ocean Waves**, **Classic Chillout**) или собственным MP3.

## 🛡️ Безопасность и прозрачность разрешений

* **HTTPS по умолчанию (`network_security_config.xml`)**: Незашифрованный HTTP-трафик отключён глобально (`cleartextTrafficPermitted="false"`), с минимальными исключениями только там, где это необходимо.
* **Безопасный просмотр WebView включён**: Google Safe Browsing активен (`EnableSafeBrowsing=true`) без отправки телеметрии (`MetricsOptOut=true`).
* **Проверяемые OTA-обновления**: Перед установкой любого обновления с GitHub `AppUpdateManager` сверяет хэш **SHA-256** (`version.json`), **имя пакета** и **сертификат подписи APK**.
* **Без широких разрешений к памяти (`Без MANAGE_EXTERNAL_STORAGE`)**: Все локальные обои, видео, MP3, фото и резервные копии выбираются через безопасный **Storage Access Framework (SAF)**.
* **Назначение разрешений**: `INTERNET`/`ACCESS_NETWORK_STATE` (IPTV, панели, магазин, OTA), опциональное `ACCESS_COARSE_LOCATION` (примерная погода города), опциональное `RECORD_AUDIO` (только для Голосового поиска `🎤`), `REQUEST_INSTALL_PACKAGES`/`REQUEST_DELETE_PACKAGES` (только по прямому действию пользователя), `BIND_VPN_SERVICE` (локальный щит AdGuard DNS) и `RECEIVE_BOOT_COMPLETED`.

## 🎮 Горячие клавиши пульта

| Клавиша | Действие |
| :--- | :--- |
| **Стрелки (D-Pad)** | Быстрое и плавное перемещение между приложениями, каналами и настройками. |
| **Кнопка OK / Центр** | Запуск приложения или открытие канала. |
| **Долгое нажатие OK** | Меню управления приложением/каналом (Перемещение, Блокировка PIN, Скрытие, Игры, Инфо/Удаление). |
| **Цифровые клавиши (`0–9`)** | **Быстрый переход по номеру канала**: введите номер канала на Главном экране, в списке IPTV или плеере (`OK` — подтвердить, `Назад` — исправить). |
| **Кнопка Menu (`☰` Три линии)** | Зависит от экрана: на **Главном экране** открывает **Настройки**, в **IPTV** (список и плеер) открывает **Настройки IPTV** (`INFO`/`GUIDE` переключает панель канала), а в **Веб-порталах и Играх** переключает **Виртуальную мышь**. |
| **Кнопка Голос / Google Assistant (`🎤`)** | Открывает встроенный голосовой поиск приложений и IPTV-каналов. |
| **Кнопка «Назад»** | Безопасный возврат на предыдущий экран или на домашнюю страницу. |
