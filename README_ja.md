## 🚀 オールインワン・ソリューション

今日の多くのスマート TV ランチャーは、強制広告、重い動画プレビュー、不要なおすすめ表示、動作の重い UI で溢れています。

**Salsa TV Launcher** はその正反対を目指して設計されました。単なるホーム画面ではなく、必要な TV 機能をすべてひとつのクリーンで高速、完全広告なしのハブに集約したメディアセンターです。

### ✨ 統合されたコアモジュール
1. **🚀 超高速＆軽量ランチャー**：1秒未満の起動、GPU アクセラレーションによるフォーカス移動、並列アイコン事前読み込み、CPU 負荷ゼロ。
2. **📺 内蔵 IPTV ＆ お気に入り行**：M3U プレイリストに対応し、ホーム画面から1クリックでお気に入りチャンネルを再生。
3. **🎥 MiniTube**：TV リモコン操作とゲスト再生に対応した軽快な YouTube TV Leanback 体験。
4. **📥 Mini Downloader**：スマートな1クリックインストーラーを備えた高速ファイル＆ APK ダウンローダー。
5. **🛒 Salsa Store**：Android TV 向けツールやユーティリティを簡単に閲覧・導入できる Web アプリストア。
6. **🕹️ 4つのゲームポータル**：ダウンロード不要ですぐ遊べる数千本の HTML5 オンラインゲーム（**CrazyGames**、**Poki**、**Playhop**、**EasyGames**）。
7. **🛡️ システム全体の広告＆トラッカーブロック**：内蔵 AdGuard DNS 保護により、テレビ全体のポップアップ、バナー、追跡をブロック。

## 🌟 新機能と最新の強化点

### 🆕 バージョン 3.1 の新機能
* **🛒 `Salsa Store` 100% ライブ読み込み（`https://auratv.freedev.app/index.html`）＆ ネイティブ TV カテゴリ表示**：アプリ内にアプリ名を一切保存せず、**Salsa Store** を開くたびに `https://auratv.freedev.app/index.html` から最新のアプリ名と情報をライブ取得します。ネイティブのカテゴリ画面で最初に **ウェブブラウザ（Web Browsers）**、次に **ソーシャルメディア（Social Media）**、その後に残りのカテゴリを表示します。
* **⌨️ Webサイト内の検索・テキスト入力欄クリックで標準キーボードを自動表示（YouTubeを除く）**：Webページやブラウザ内の入力欄・検索ボックスをクリックすると、即座にシステムの標準キーボードが表示され文字入力が可能です（独自キーボードを持つ **YouTube** ページは除外）。
* **🔐 プロフィール別PINシステム、2回入力確認、プロフィール入室ロック＆管理者 `Master PIN`**：初期PIN（`1234`）を完全廃止し、ロック機能を使う前に4桁のPINを**確認のため2回入力して新規登録**する方式に刷新。設定画面ではPINを常に伏せ字（`••••`）で表示し、変更・解除には現在のPINが必要です。各プロフィールには**切り替え時のPIN入室ロック**を設定でき、削除不可の管理者プロフィール **`Main`（Admin）** のPINは、他のプロフィールのPINを忘れた際にも入室・編集できる **`Master PIN Code`** として機能します。
* **🎙️ Android TV 音声検索の認識安定性を強化**：Android TV の音声認識サービス（`katniss`）へ直接接続し、Bluetoothリモコンマイクの待機時間延長と自動リトライを搭載。
* **🛠️ Launcher Manager（`設定 > システムショートカット > Launcher Manager` — ローカル ADB による標準ホーム設定）**：外部 PC やスマホを使わず、テレビ自身のローカル ADB 接続（`127.0.0.1:5555`）で `cmd package set-home-activity --user 0` を実行し、再起動後も維持される永続的な標準 `HOME` ランチャーに設定できる 3 ステップウィザードを搭載（標準ランチャーの無効化およびワンクリック復元にも対応）。
* **🎨 ユーザー別ダイナミック・アクセントカラーテーマ**：各プロフィールで選択したアクセントカラーが、アプリ全体の従来の黄色／ゴールド表示（挨拶メッセージ、テキスト強調、アプリ／ゲーム／Web セクション見出し・アイコン、設定、IPTV、Salsa Store、フォーカス枠）に動的に反映されます。
* **👤 マルチユーザープロフィール＆ユーザー別設定分離（`Profiles / Users`）**：家族それぞれに独立したプロフィールを作成可能。**外観・アクセントカラー・壁紙**、**スクリーンセーバー**、**言語**、**IPTV お気に入り＆並び順**、**アプリ／Web／ゲームの並び順**、任意の **4桁プロフィール PIN**、および**ユーザー別のセクション管理**（**IPTV**・**アプリ**・**Web**・**ゲーム**の表示／PINロック／完全非表示）を個別に保存します。上部バーの最外端（**LTRでは右端、RTLでは左端**）に配置されたフラットで枠線のない円形アバターアイコンから瞬時に切り替え可能です。
* **🔢 数字キーによるクイックチャンネル選局（`0–9`）＆高コントラスト番号バッジ**：ホーム画面、IPTV チャンネル一覧、再生中のプレーヤーでリモコンの数字キー（`0–9`）を押すだけで該当番号のチャンネルへ即座にジャンプ。視認性の高いチャンネル番号バッジ（半透明の白地に黒数字）も搭載。
* **🎞️ 本体／USB からのローカル動画スクリーンセーバー（`Media3 / ExoPlayer`）**：テキストやオーバーレイ一切なしの `m.youtube.com` 全画面再生に加え、権限不要の安全な **Storage Access Framework（SAF）** でテレビ本体や USB の動画ファイルを選び、シームレスに全画面ループ再生できます。
* **📡 放送風テキスト・スクリーンセーバー（12種のアニメーションテーマ、ダーク動的背景＆音声読み上げ）**：6種のクラシックテーマ＋6種のクリエイティブ新作テーマ（**Aurora Silk**、**Synthwave 80s**、**Cosmic Orbit**、**Royal Arabesque**、**Audio Studio Equalizer**、**Crystal Prism Hologram**）の全12種を搭載。各テーマに**専用ダーク動的背景と対比カラーの揺らぐシャドウ**を採用し、設定画面でライブプレビュー可能。行編集・表示時間（`3〜15秒`）、読み上げ完了を待って次へ進む **音声読み上げ（TTS）**、環境音・ローカル MP3 に対応。
* **📺 IPTV スマートエラー回復（`次のチャンネル`＋15秒自動リトライ）＆ 秘密の3回OKギフト解除**：IPTV チャンネルが読み込めない際、**次のチャンネル** ボタンのみにフォーカスしたシンプルな画面と **15秒カウントダウン** を表示し、未選択時は自動で再試行します。また、空の IPTV カードで `OK` を3回押すと、ギフトアニメーションとともに内蔵プレイリストが解放されます。
* **🛒 Salsa Store 上位カテゴリ＆クリーンな `m.youtube.com` 動画スクリーンセーバー**：**Salsa Store** の全9カテゴリ（厳選された Android TV ツール＆プレーヤー・オフライン対応）で **Web ブラウザ** と **SNS** を最上部に配置。動画スクリーンセーバーは画面上のテキストや HUD を一切表示せず、`m.youtube.com` でクリーンな全画面再生を行います。
* **🎨 ライブ UI 設定 HUD（`Live UI Settings`）— 時刻形式を直接切替**：ホーム画面の透過設定バーに、時計サイズ・日付形式と並んで **時刻形式（`24時間 • 22:00` / `12時間 • AM/PM`）** を直接追加。4K壁紙、明るさ、アプリ位置、グリッド数、透過率、挨拶、天気、夜間フィルター、Material You、軽量モードもリアルタイムプレビュー対応。
* **🖥️ ダッシュボード・スクリーンセーバー、ニュース音声読み上げ＆統一クリア音楽**：**天気**・**ニュース**・**経済**・**サッカー**・**すべて自動切替**に対応。ニュースモードでは全6件を読み終えてから切り替わる **音声読み上げ（TTS）** を備え、すべての情報ボードでスライドショー等と同じ高明瞭な背景音楽（**Bossa Nova**、**Smooth Jazz**、**Calm Ocean Waves**、**Classic Chillout**、環境音、MP3）と音声読み上げ時の自動音量ダウンに対応。
* **🌙 デフォルトのスクリーンセーバー待機時間を10分に変更**：既定の無操作タイマーを **10分** に更新（2・5・10・15・30分または無効に変更可能）。
* **🖱️ 端から端まで届く仮想マウス、文脈対応3本線メニュー（`☰`）＆ 起動画面バージョン**：Webポータル・HTML5ゲームの仮想マウスが画面の上下端まで到達。**メニューキー（`☰` 三本線）** はホーム画面で **設定**、IPTV で **IPTV設定** を開き、Webポータル／ゲームでは **仮想マウス** を切り替えます。`OK` 長押しの誤起動防止、新 **Salsa Store** アイコン、`v3.0` 表示、**GitHub OTA 自動アップデート** に対応。
* **🌐 4つのライブ情報ダッシュボード、Webポータル＆21言語 v3.0 エンジン**：**天気**・**ニュース**（21言語・5部門）・**経済＆マーケット**・**サッカー（365Scores）**、デフォルトポータル（**YouTube TV**・**Google**・**CrazyGames**・**Poki**・**Playhop**・**EasyGames**）、見切れない上部バー、軽量 60FPS v3.0 エンジン。

### ⚡ 圧倒的なパフォーマンスと瞬時の起動
* **アイコンとバナーの並列プリロード**：アプリ、アイコン、バナーをバックグラウンドのマルチコア CPU で並列デコードし、起動直後から即座に表示します。
* **110ms の超高速 D-Pad ナビゲーション**：ハードウェア高速化された `graphicsLayer` 描画と 110ms の俊敏なアニメーションにより、リモコン操作の遅延を解消。
* **GPU 最適化アンビエントグロー**：重いブラー処理やノイズレイヤーを滑らかな放射状グラデーションに置き換え、あらゆる TV で安定した 60fps を実現。
* **クリーンなホーム画面（下部編集ボタンを削除）**：画面下部の余計なボタンを省き、リモコンの **`OK` 長押し** で手軽に並び替えできます。

### 🌙 インテリジェント・スクリーンセーバーとシステム引き継ぎ
* **外部スクリーンセーバーへの自動引き継ぎ（`無効` モード）**：内蔵スクリーンセーバーを無効にするとスリープ抑制ロック（`FLAG_KEEP_SCREEN_ON`）が解除され、Android TV 標準や外部スクリーンセーバーが正常に起動します。
* **内蔵アンビエント・スリープモード（`有効`）**：タイマー（2、5、10、15、30分）を設定すると、3つのスタイルから選んで表示できます：
  * **時計と日付モード**：焼き付き防止（ドリフト保護）付きの明るいデジタル時計。
  * **4K 壁紙＆情報モード**：45度のコーナーグラデーション上に時刻、日付、挨拶を美しく表示。
  * **シネマティック動画スクリーンセーバー（`m.youtube.com`、カスタム YouTube 動画＆ライブプレビュー対応）**：暖炉、冬の山小屋、熱帯の滝を画面上のテキストやオーバーレイなしの `m.youtube.com` 全画面でクリーンに再生。**任意の YouTube 動画 URL/ID の追加**、プリセットの削除・復元、設定画面からの**即時ライブプレビュー再生**に対応しています。
  * **フォトスライドショー・スクリーンセーバー（`Slideshow`）**：本体ストレージ／USBの指定フォルダ、選択した写真、または内蔵4Kギャラリーをスライド再生。表示時間（`5秒`〜`5分`）、モーション（**Ken Burns**／**ソフトズーム**／**静止**）、6種類の切り替え効果、7種類の環境エフェクト（**降雪 ❄️**、**ホタル ✨**、**小雨 🌧️**、**紅葉 🍂**、**桜吹雪 🌸**、**星空 ⭐**、**ボケ光 🔮**）、コーナー時計、クリアな内蔵BGM（**Bossa Nova**、**Smooth Jazz**、**Calm Ocean Waves**、**Classic Chillout**）や MP3 再生に対応。

### 🎛️ ランチャーとホーム画面レイアウトの調整
* **上部バーのアイコンモード（コントロールセンター／直接設定／両方表示）**：ホーム画面右上に「コントロールセンター」を表示するか、コントロールセンターをスキップして「設定アイコン」を直接表示するか、「両方のアイコンを同時に表示」するかを選択できます。
* **設定アイコンへの初期フォーカス**：起動時にカーソルが右上の設定アイコンへ自動的に合わさり、素早く設定できます。
* **アプリ行の垂直オフセット**：アプリの行位置を下げて（180dp〜380dp）、高精細な 4K 壁紙やオーロラ背景を引き立てます。
* **グリッド密度の調整**：テレビ画面に合わせて 1行あたり 4、5、6、7 個から選択可能。
* **グラスモーフィズム透過率**：カードの透明感を 10%〜100% で調整可能。
* **サイドロード／モバイルアプリ表示切替＆ Material You ダイナミックカラー**：Android TV 専用アプリのみ表示するか、**サイドロードしたスマホ／タブレット用 APK を含む全インストール済みアプリを表示**するかを切り替え可能。非表示アプリの一括復元、並び順のリセット、**Material You ダイナミックカラー**にも対応。

### 🎙️ ユニバーサル音声検索、システム標準音声アシスタント、コントロールセンター、IPTV管理
* **ユニバーサル音声＆即時検索 (`🎤`)**: リモコンのマイクや画面キーボードを使って、インストール済みアプリ、ライブIPTVチャンネル、Web/YouTubeを同時に検索できます。
* **システム標準デジタル音声アシスタント (`VoiceInteractionService`)**: Salsa TV を Android TV の**デフォルト音声アシスタント**に設定でき、リモコンのマイクボタンから直接起動できます。
* **クイックコントロールセンター (`Control Center`)**: 12h/24h表示切替、動的背景、スクリーンセーバーの即時起動、音声検索、Wi-Fiや設定へ素早くアクセスできるパネル。
* **マルチプレイリスト IPTV マネージャー＆スマート Web ブックマーク**: 複数の **M3U プレイリスト**や **XMLTV EPG URL** の追加・切替・更新に対応。Web ブックマークは**高解像度アイコン自動取得 (`WebBookmarkIconResolver`)** を備え、YouTube ブックマークは **YouTube TV Leanback インターフェース**で開きます。
* **タッチ＆リモコン`OK`対応IPTV情報バー（チャンネルストリップ内蔵）**: IPTV視聴中に画面をタッチするかリモコンの`OK`を押すと情報バーが表示され、内蔵の**横スクロール・チャンネルバー**から直接チャンネルを切り替えられます（EPG番組表、スリープタイマー対応）。
* **クリーンな下部スタート＆240dpスマート時計縮小**: 起動時はアプリとチャンネルが画面下部（6段階の名前付き設定、標準`450`）に配置され、カーソルはどこにもフォーカスせず、アイコンが上部`240dp`に達すると時計が自動的に縮小します。

### 🔒 プライバシー、デュアルモード DNS シールド、ストレージ管理、アプリロック
* **内蔵アプリ・ストレージマネージャー**: インストール済みアプリを容量（MB）順に表示し、アプリ情報の確認や不要なアプリの直接アンインストールでテレビの空き容量を確保できます。
* **デュアルモード DNS シールド（広告ブロック＆PIN保護ファミリー保護モード）**: Root 不要のローカル VPN 型 DNS フィルタリングにより、**広告・トラッカーブロック**または**ファミリー保護モード**を選択できます。**ファミリー保護モードの解除や PIN 変更には4桁の PIN 入力が必須です。**
* **10個のシステム・クイックショートカット（`Launcher Manager` 搭載）**: 設定画面から **Wi-Fi、イーサネット、ディスプレイ、サウンド、日付と時刻、システム設定一覧、アプリ情報、ストレージマネージャー、Launcher Manager（ローカル ADB 標準ホーム設定）、開発者向けオプション**へワンクリックで移動可能。
* **PIN コードによるアプリロック**：4桁の PIN コードで大切なアプリを保護。
* **並び替えと非表示**：アプリの移動、カテゴリ分け（アプリ／ゲーム）、不要なシステムアプリの非表示。
* **安全な戻るナビゲーション**：ホーム画面で戻るボタンを押しても誤って OS 画面へ終了するのを防ぎます。

> ⚠️ **キッズ／ファミリー保護モードに関する重要なご注意**：ランチャー内での解除は4桁の PIN で保護されています。ただし、**ランチャー単体では他のアプリやシステム `Home` ボタンからの離脱を完全に防ぐことはできません**。**Salsa TV Launcher** を**標準ホームアプリ**に設定し、**システム設定**もアプリロック PIN で保護することを推奨します。

## 🛡️ セキュリティと権限の透明性

* **デフォルト HTTPS 通信（`network_security_config.xml`）**：非暗号化 HTTP 通信を原則無効化（`cleartextTrafficPermitted="false"`）し、必要な例外のみ最小限に限定しています。
* **WebView セーフブラウジング有効**：全 WebView で Google Safe Browsing を有効化（`EnableSafeBrowsing=true`）、統計送信を無効化（`MetricsOptOut=true`）。
* **検証済み OTA 自動アップデート**：GitHub からの更新 APK をインストールする前に、**SHA-256 ハッシュ**（`version.json`）、**パッケージ名**、**APK 署名証明書**の一致を厳格に検証します。
* **広範なストレージ権限不使用（`MANAGE_EXTERNAL_STORAGE` なし）**：壁紙・ローカル動画・MP3・写真・バックアップはすべて安全な **Storage Access Framework（SAF）** を使用します。
* **権限の用途**：`INTERNET`/`ACCESS_NETWORK_STATE`（IPTV・情報ボード・ストア・OTA）、任意の `ACCESS_COARSE_LOCATION`（都市レベルの天気）、任意の `RECORD_AUDIO`（音声検索 `🎤` のみ）、`REQUEST_INSTALL_PACKAGES`/`REQUEST_DELETE_PACKAGES`（ユーザー操作時のAPK導入／削除）、`BIND_VPN_SERVICE`（ローカル AdGuard DNS 保護）、`RECEIVE_BOOT_COMPLETED`。

### 方法 1：APK の直接ダウンロード
最新の公式リリース APK を Android TV デバイスに直接ダウンロードします：

👉 **[最新の Salsa TV Launcher APK をダウンロード](https://github.com/OsamaSalsa/Salsa-TV-Launcher/raw/refs/heads/main/salsa-tv-launcher.apk)**  
👉 **[Downloader 短縮コード / 直リンク：aftv.news/5157967](http://aftv.news/5157967)**

### 方法 2：ADB を使ったインストール
```bash
# Android TV の IP アドレスに接続
adb connect <TV_IP_ADDRESS>:5555

# APK をインストール
adb install -r salsa-tv-launcher.apk
```

### 方法 3：デフォルトのホームランチャーに設定（内蔵ローカル ADB Launcher Manager）
1. Salsa TV Launcher 内の **設定 > システムショートカット > Launcher Manager** を開きます。
2. 3ステップウィザードに従って **開発者向けオプション** と **USB／ネットワークデバッグ** を有効にし、**接続 (127.0.0.1:5555)** を押して「常に許可」にチェックを入れます。
3. **デフォルト HOME に設定** を押すと、外部 PC なしで再起動後も維持される標準ホームに設定されます（いつでも標準ランチャーを復元可能）。

| リモコンのキー | 動作 |
| :--- | :--- |
| **十字キー (D-Pad)** | アプリ、チャンネル、設定の間を滑らかかつ高速に移動。 |
